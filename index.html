How I work

How I like to work.

A few habits that show up in every project.

  • 01

    Question first

    I write the business question down before I open the data. It decides which charts make it to the page and which ones stay out.

  • 02

    Check the numbers twice

    I recalculate key figures in a second tool. In Trailwave Freight, an SQL script checks every DAX measure in the report.

  • 03

    Plain words

    Every page ends with a takeaway someone can repeat in a meeting. No jargon unless the audience uses it.

  • 04

    Honest about limits

    Every README has a section on what the data cannot tell you, like simulated delivery times or a single year of population data.

  • 05

    Teamwork

    Years of group projects at university taught me to split the work, agree on scope and deliver on time.

  • 06

    Learning on my own

    I moved from Geography into data by building real projects, and each one is versioned and documented on GitHub.
